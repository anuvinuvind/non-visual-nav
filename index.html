Carrier test


Stationary path-localization: find the peak of a fixed spike profile (×1 on the active carrier) along a virtual centerline. Move the phone sideways only — no walking. Each user runs all 7 carriers in Latin-square order (14 users for balance). After you confirm a guess you see a symmetrical peak graph and accuracy %. No NASA-TLX.
